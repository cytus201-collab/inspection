# 監造抽查紀錄（PWA v8）

## 使用流程
1. 工程清單 → 新增工程 → 填工程基本資料（工程名稱、編號、監造人員等會自動帶入抽查表）
2. 點工項（放樣、植筋、矽酸鈣板隔間…共 12 項），另有不定期抽查、勞安衛生抽查、建築師督導（僅照片）
3. 在施工前／施工中／施工完成任一階段按「新增抽查」，每次抽查一筆，編號自動產生
4. 填完按「確認並產生 A4 表單」→「列印 / 存成 PDF」
5. 不定期抽查：從各工項抽查標準挑選項目或自訂項目，格式依公司「不定期抽查紀錄」
6. 勞安衛生抽查：18 項工地職安檢查，格式同不定期抽查紀錄
8. 抽查標準可在表單中逐項修改、移除或新增；按「將本表的抽查標準設為本工程預設」後，同工程之後新增的表單都會套用
9. 抽查照片：在每一張抽查單（施工前／中／完成、不定期、勞安、材料進場抽查表）內拍照或從相簿加入，輸出時接在抽查表後，每頁 6 張（2×3）附說明；照片存在瀏覽器的 IndexedDB，匯出備份檔時一併打包
10. 材料進場抽查紀錄表：在材料明細頁新增，完成後自動填入該材料的抽查日期與結果
7. 材料抽查管制：匯入「材料設備送審管制總表」（PDF、Excel、CSV），逐項記錄送審、進場、抽查日期與結果，可列印 A4 橫式管制總表

## 匯入材料管制表的注意事項
- PDF 需為電子檔（可選取文字），掃描圖片檔請改用 Excel 或 CSV
- 讀取 PDF、Excel 需要網路（第一次會下載解析元件）；CSV 離線也能匯入
- 重複匯入選「合併」會保留已登錄的日期與抽查結果

## 檔案
- mat-parse.js：材料管制表解析
- data.js：所有工項與抽查項目。要新增工項或修改標準只改這個檔，改完把 version 加一
- index.html / style.css / app.js：程式
- sw.js：離線快取，改版時把 VERSION 加一
- 改版時也要把 index.html 裡 style.css、data.js、mat-parse.js、app.js 後面的 ?v= 數字加一，避免手機讀到新舊混用的檔案
- manifest.webmanifest、icon-*.png：加入手機主畫面用

## 資料保存
資料存在各裝置的瀏覽器中，不會上傳。換裝置或清除瀏覽器資料前，請在工程清單頁「匯出備份檔」，到新裝置再「匯入備份檔」。

## 試用與上線
- 電腦試用：解壓後雙擊 index.html
- 上線：上傳到 GitHub Pages（Settings → Pages → main → Save），手機開啟網址後「加入主畫面」即可離線使用

## 本工程抽查工項
工程頁「選擇本工程要抽查的工項」勾選需要的工項；已有紀錄的工項不會被隱藏。

## 定型文
實際抽查情形下方的按鈕（符合、無此項…）可一鍵填入，並在尚未判定時一併帶入 ○ 或 ／。定型文清單在 data.js 的 phrases 修改。

## Google Apps Script 共編版
- apps-script/Code.gs：貼到 Apps Script 專案，部署為網頁應用程式（執行身分：存取網頁應用程式的使用者；誰可以存取：所有已登入 Google 帳戶的使用者）
- 網頁內容直接讀取本專案 main 分支，GitHub 更新後最多 10 分鐘自動生效（網址加 ?refresh=1 可立即更新）
- 資料存於試算表「監造抽查資料庫」（_sync 隱藏工作表、抽查紀錄總覽），照片存於同資料夾「監造抽查照片」
- 共編：把雲端資料夾「室內裝修抽查表單」共用給同事（編輯者）；同一筆紀錄兩人同時修改時，以最後儲存者為準
